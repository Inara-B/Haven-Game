I created a platformer game using Godot and Itch.io. It was my first time using Godot so I used this game to help learn the basic functions. 
I created Bunny Hop! A vertical platforming game where you guide a purple bunny through colourful cotton candy sky levels, maze paths, and tricky platforming jumps! 
Leap, and navigate your way through a tower of platforms set against cloud-filled skies!
Starting from the bottom floor, you'll have to weave through maze-like passages, precision jumps, and floating platforms to reach the very top Use either AWSD or arrow keys to help!
I used assets from https://github.com/russs123/Godot-Platformer 
The game is accessible through this link: https://butterfly125.itch.io/haven-platform-game
